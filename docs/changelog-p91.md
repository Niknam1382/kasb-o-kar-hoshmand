# پ۹۱ — پنلِ وبِ فقط‌خواندنیِ عملیاتی (`GET /panel`) (۲۰۲۶-۱۱-۱۶)

ادامهٔ پ۸۷: همان دیتایِ `/ops/status` این‌بار به شکلِ HTML راست‌به‌چپ برایِ چشمِ آدم، با تازه‌سازیِ خودکار
هر ۳۰ ثانیه (`meta refresh`) و بدونِ هیچ فرم/دکمه/جاوااسکریپتی.

• احراز: HTTP Basic — نامِ کاربر دلخواه، رمز = `METRICS_TOKEN`. بدونِ کلیدِ تنظیم‌شده مسیر ۴۰۴ است و
  با رمزِ اشتباه ۴۰۱ + چالشِ `WWW-Authenticate: Basic realm="ops"`. ورودیِ Base64ِ خراب هم رد می‌شود.
• بخش‌ها: پروسه‌ها (زنده/بی‌ضربان)، سیستم (هسته، بار، رم، دیسک)، استخرِ دیتابیس، هوشِ مصنوعی (کلیدها،
  سقف، در حالِ انجام، فشار)، یافته‌هایِ عیب‌یاب (با شدتِ رنگی)، آستانه‌هایِ موثر، کانال‌ها و فروشگاه‌ها،
  و شمارنده‌هایِ جمع‌شده از همهٔ پروسه‌ها.
• بخشِ تازهٔ «کانال‌ها»: `capacity_service.channel_summary` ⇒ ۱۲ فروشگاهِ اول + تعدادِ کلِ فروشگاه‌هایِ
  فعال + تعدادِ اتصال‌هایِ اینستاگرام و بله. «بله» از **وجودِ** کلید شمرده می‌شود، نه مقدارش.
• حریمِ خصوصی: هیچ دادهٔ مشتری، هیچ متنِ گفتگو، هیچ مبلغِ سفارش و هیچ رازی در صفحه نیست؛ تست صراحتاً
  دنباله‌هایِ `encrypted_token`، `webhook_secret`، `merchant_id`، `sk-`، `gAAAAA` و خودِ کلید را می‌گیرد.

**باقیِ پنل (عمداً انجام نشد):** نوشتنِ داده، لاگینِ کاربر-محور، WebSocketِ زنده و نمایِ چندکانالهٔ گفتگو ⇒
