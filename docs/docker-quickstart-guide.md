## ۱. نصبِ Docker Desktop

Docker یه برنامه‌ست که کلِ ربات (کد + دیتابیس) رو توی یه «جعبه‌ی ایزوله»
اجرا می‌کنه، بدونِ اینکه لازم باشه خودت پایتون یا PostgreSQL رو دستی روی
سیستمت نصب کنی.

1. برو به آدرسِ **[docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/)**
2. روی دکمه‌ی دانلود برای ویندوز (یا مک، اگه مک داری) کلیک کن.
3. فایلِ نصبی که دانلود شد رو باز کن و مراحلِ نصب رو با «Next» جلو برو
   (تنظیماتِ پیش‌فرض رو دست نزن).
4. بعد از نصب، سیستمت رو **ری‌استارت کن** (این مرحله معمولاً لازمه).
5. بعد از ری‌استارت، Docker Desktop خودش باز می‌شه یا از منوی استارت بازش کن.
   ممکنه ازت بخواد یه حساب بسازی یا لاگین کنی — رد کردنش هم معمولاً امکان‌پذیره
   («Continue without signing in» یا مشابهش).
6. صبر کن تا آیکونِ نهنگِ کوچیک (🐳) که کنارِ ساعتِ ویندوز (پایین-راستِ صفحه)
   ظاهر می‌شه، **ثابت** بمونه (نه در حالِ چرخش/لودینگ). این یعنی Docker آماده‌ست.

**چطور مطمئن بشم درست نصب شده؟** یه پنجره‌ی «PowerShell» باز کن (روی دکمه‌ی
استارتِ ویندوز کلیک کن، بنویس «PowerShell»، و روی نتیجه کلیک کن) و این دستور
رو بزن:

```powershell
docker --version
```

اگه یه چیزی مثلِ `Docker version 27.x.x` نشون داد، همه‌چیز درسته.

## ۲. استخراجِ فایل‌های پروژه

1. فایلِ `kasb-o-kar-hoshmand.zip` که قبلاً برات فرستاده شده رو پیدا کن (توی
   پوشه‌ی Downloads معمولاً).
2. روش راست‌کلیک کن و «Extract All...» رو بزن.
3. یه مسیرِ **ساده** برای استخراج انتخاب کن — پیشنهاد می‌کنم مستقیم بریزیش توی
   `C:\kasbokar` (نه توی یه پوشه‌ی OneDrive یا مسیری با فاصله/حروفِ فارسی، چون
   گاهی باعثِ دردسر می‌شه).
4. بعد از استخراج، باید یه پوشه‌ی `kasb-o-kar-hoshmand` با فایل‌هایی مثلِ
   `Dockerfile`، `docker-compose.yml`، `app`, `requirements.txt` و... توش
   ببینی.

## ۳. ساختنِ دو ربات در تلگرام

اینجا دو تا ربات می‌سازیم: یکی **«ربات اصلی»** (که خودت به‌عنوانِ ادمین و
فروشگاه‌دار باهاش کار می‌کنی)، و یکی **«ربات فروشگاهیِ نمونه»** (که بعداً
داخلِ پنل ثبتش می‌کنی تا مشتری‌های فرضی باهاش چت کنن).

### ۳-۱. ساختِ ربات اصلی

1. توی تلگرام، توی جستجو بنویس **`BotFather`** و روی حسابِ آبی‌تیکِ رسمیش
   کلیک کن (یوزرنیمش `@BotFather` هست).
2. بهش بفرست: `/newbot`
3. یه اسمِ دلخواه بنویس، مثلاً: `فروشگاه‌سازِ من` (این اسمیه که کاربرها می‌بینن).
4. یه یوزرنیم بنویس که **حتماً باید به `bot` ختم بشه**، مثلاً: `mykasbokar_bot`
   (اگه گفت قبلاً گرفته شده، یه چیزِ دیگه امتحان کن).
5. BotFather یه پیام می‌فرسته که توش یه **توکن** هست — یه رشته‌ی طولانی شبیهِ
   `123456789:AAHk3j...`. این رو یه‌جا (مثلاً Notepad) کپی کن و نگه دار؛
   بهش می‌گیم **توکنِ ربات اصلی**.

### ۳-۲. ساختِ ربات فروشگاهیِ نمونه

دقیقاً همینِ مراحل رو یه‌بارِ دیگه تکرار کن (بازم `/newbot` به BotFather بده)،
با یه اسم و یوزرنیمِ متفاوت، مثلاً `فروشگاهِ آزمایشیِ من` و
`mykasbokar_shop_bot`. توکنی که می‌گیری رو هم جدا نگه دار — بهش می‌گیم
**توکنِ ربات فروشگاهی**.

### ۳-۳. گرفتنِ آیدیِ عددیِ خودت

1. توی تلگرام جستجو کن: **`@userinfobot`**
2. بهش هر پیامی بفرست (مثلاً «سلام»)
3. یه عدد بهت می‌ده زیرِ «Id» — این آیدیِ عددیِ توئه، یه‌جا کپیش کن.

الان باید سه چیز داشته باشی: **توکنِ ربات اصلی**، **توکنِ ربات فروشگاهی**، و
**آیدیِ عددیِ خودت**.

## ۴. تنظیمِ فایلِ .env

1. توی پوشه‌ی پروژه (`C:\kasbokar\kasb-o-kar-hoshmand`)، فایلِ
   `.env.docker.example` رو پیدا کن.
2. یه کپی ازش بگیر (راست‌کلیک → Copy، بعد راست‌کلیک → Paste) و اسمِ کپی رو
   دقیقاً بذار: **`.env`** (بدونِ هیچ پسوندِ دیگه‌ای).

   > اگه ویندوز پسوندهای فایل رو نشون نمی‌ده و نمی‌تونی مطمئن بشی اسمش دقیقاً
   > `.env` شده (نه `.env.txt`)، از File Explorer بالا، تبِ «View» رو باز کن
   > و تیکِ «File name extensions» رو بزن تا پسوندها دیده بشن.

3. فایلِ `.env` رو با Notepad باز کن (راست‌کلیک → Open with → Notepad).
4. این خط‌ها رو پیدا کن و مقدارِ جلوشون رو پر کن:

   ```
   MAIN_BOT_TOKEN=توکنِ ربات اصلی رو اینجا بچسبون
   ADMIN_TELEGRAM_IDS=آیدیِ عددیِ خودت رو اینجا بچسبون
   ```

   بقیه‌ی خط‌ها (`DATABASE_URL`، `RUN_MODE`، `AUTH_MODE`) رو **دست نزن** —
   از قبل درست تنظیم شدن.

5. `ENCRYPTION_KEY` رو فعلاً خالی بذار؛ توی قدمِ بعد می‌سازیمش. فایل رو ذخیره
   کن (Ctrl+S) و ببندش.

### ساختنِ کلیدِ رمزنگاری

1. یه پنجره‌ی PowerShell باز کن **داخلِ پوشه‌ی پروژه**: توی File Explorer
   وارد پوشه‌ی `kasb-o-kar-hoshmand` شو، توی نوارِ آدرسِ بالا کلیک کن، بنویس
   `powershell` و Enter بزن — یه پنجره‌ی PowerShell دقیقاً توی همون پوشه باز
   می‌شه.
2. این دستور رو بزن تا اول تصویرِ داکرِ ربات ساخته بشه (چند دقیقه طول می‌کشه،
   طبیعیه):

   ```powershell
   docker compose build
   ```

3. بعد از اینکه تموم شد، این دستور رو بزن تا یه کلیدِ رمزنگاریِ تازه بسازه:

   ```powershell
   docker compose run --rm bot python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
   ```

4. یه رشته مثلِ `xY3k...==` چاپ می‌شه. کپیش کن.
5. دوباره فایلِ `.env` رو با Notepad باز کن و جلوی `ENCRYPTION_KEY=` بچسبونش،
   طوری که بشه مثلاً: `ENCRYPTION_KEY=xY3k...==`
6. ذخیره کن و ببند.

## ۵. بالا آوردنِ همه‌چیز

توی همون پنجره‌ی PowerShell (که توی پوشه‌ی پروژه بازه)، این دستور رو بزن:

```powershell
docker compose up
```

چند خط لاگ می‌بینی — دیتابیس بالا میاد، مایگریشن‌ها خودکار اجرا می‌شن، و بعد
ربات استارت می‌شه. وقتی خطی شبیهِ این دیدی، یعنی **آماده‌ست**:

```
bot-1  |  در حالِ اجرای ربات...
```

این پنجره رو **باز نگه دار** (بستنش ربات رو خاموش می‌کنه). حالا برو سراغِ
تلگرام و به **ربات اصلی**ت پیام `/start` بده — باید جواب بده!

> نکته: اگه می‌خوای این پنجره رو ببندی ولی ربات روشن بمونه، به‌جاش از دستورِ
> `docker compose up -d` استفاده کن (بخشِ «دستوراتِ روزمره» پایین‌تر رو ببین).

## ۶. چک‌لیستِ کاملِ تستِ امکانات

حالا که ربات روشنه، این مراحل رو به‌ترتیب امتحان کن:

### ۶-۱. ثبت‌نام و ورود به‌عنوانِ ادمین
به ربات اصلی `/start` بده. چون آیدیِ تلگرامت رو توی `ADMIN_TELEGRAM_IDS`
گذاشتی، هم گزینه‌های عادیِ فروشگاه‌داری رو می‌بینی هم دسترسیِ ادمین رو (از
منو، دکمه‌های مخصوصِ ادمین مثلِ «👥 مدیریت فروشگاه‌دارها» باید ظاهر بشن).
مراحلِ ثبت‌نام (اسم، فامیل، شماره‌موبایل، ایمیل) رو کامل کن — چون
`AUTH_MODE=test` گذاشتیم، کدِ تایید مستقیم توی همون چت نشون داده می‌شه، نیازی
به پیامک/ایمیلِ واقعی نیست.

### ۶-۲. تنظیماتِ اولیه‌ی ادمین
قیمت‌گذاریِ کیف‌پول از قبل مقادیرِ پیش‌فرضِ منطقی داره، نیازی به تنظیمِ اولیه
نیست. اگه می‌خوای بخشِ چتِ هوشمند رو هم تست کنی، از «🔑 تنظیمات کلیدها» یه
`ai_api_key` و `ai_model` (از یه سرویسِ سازگار با OpenAI API) وارد کن — این
بخش اختیاریه؛ بدونش بقیه‌ی امکانات (محصولات، پرداخت، مدیریتِ کانال، آمار)
کامل کار می‌کنن، فقط چتِ هوشمندِ مشتری جواب نمی‌ده.

### ۶-۳. فعال‌سازیِ اعتبارِ آزمایشی
بعد از ثبت‌نام، ربات پیشنهادِ یه اعتبارِ آزمایشیِ رایگان به کیف‌پولت می‌ده —
دکمه‌ش رو بزن.

### ۶-۴. ثبتِ ربات فروشگاهی
از منو، «🔑 ثبت/ویرایش توکن ربات» رو بزن و **توکنِ ربات فروشگاهی** (همونی که
مرحله‌ی ۳-۲ ساختی) رو بفرست. اگه پیام تاییدِ موفقیت اومد، یعنی وصل شد. چون
اولین‌باره، یه سوال هم می‌پرسه: این ربات قراره «🛍 فروشِ محصول» باشه یا «💬
مشاوره و خدمات»؟ برای این راهنما، «فروشِ محصول» رو انتخاب کن تا مرحله‌ی بعد
(اضافه‌کردنِ محصول) معنی داشته باشه.

### ۶-۵. اضافه‌کردنِ محصول
از «📦 محصولات» یه محصولِ آزمایشی بساز — اسم، توضیح (یا رد کن)، قیمت، عکس
(یا رد کن)، و موجودی (مثلاً ۱۰ عدد، یا رد کن برای نامحدود).

### ۶-۶. چت با ربات فروشگاهی (به‌عنوانِ «مشتری»)
حالا برو توی تلگرام و به **رباتِ فروشگاهی** (نه ربات اصلی!) پیام بده — دقیقاً
مثلِ یه مشتریِ واقعی. اگه `ai_api_key` رو تنظیم کرده باشی، باید جوابِ
هوشمند بگیری. اگه تنظیم نکرده باشی، یه پیامِ خطای مودبانه می‌بینی (طبیعیه).

### ۶-۷. تستِ عکس و پیامِ صوتی
یه عکس (مثلاً هر عکسی) به رباتِ فروشگاهی بفرست — باید هم به مشتری تاییدِ
دریافت بده، هم عکس (با تحلیلِ هوشمند، اگه ai_api_key تنظیم شده) رو برات
(روی ربات اصلی) فوروارد کنه. یه پیامِ صوتی هم امتحان کن.

### ۶-۸. مدیریتِ کانالِ اجباری
از «📢 مدیریت کانال‌های اجباری» (منوی ادمین)، یه کانالِ تلگرامیِ خودت رو
(که ادمینشی) اضافه کن — باید یه پیام از همون کانال به ربات اصلی **فوروارد**
کنی تا مالکیتش تایید بشه.

### ۶-۹. آمار و خروجیِ اکسل
از «📊 آمار» وضعیتِ فروشگاهت رو ببین. از «📤 خروجی اکسل» یه فایلِ اکسل بگیر و
بازش کن — باید استایل‌خورده (رنگی، راست‌به‌چپ) باشه.

### ۶-۱۰. کدِ معرف
از «🎁 کد معرف» کدِ اختصاصیت رو بگیر.

## ۷. دستوراتِ روزمره

همیشه این دستورات رو **داخلِ پوشه‌ی پروژه** (همون‌جایی که `docker-compose.yml`
هست) بزن.

| می‌خوام... | دستور |
|---|---|
| ربات رو بالا بیارم و پنجره رو ببندم ولی روشن بمونه | `docker compose up -d` |
| لاگ‌های زنده رو ببینم (وقتی با `-d` بالا آوردی) | `docker compose logs -f bot` |
| ربات رو خاموش کنم (دیتا حفظ می‌شه) | `docker compose down` |
| ربات رو دوباره روشن کنم | `docker compose up -d` |
| بعد از تغییرِ کد، دوباره بسازم و روشن کنم | `docker compose up -d --build` |
| کاملاً از صفر شروع کنم (**همه‌ی دیتا پاک می‌شه!**) | `docker compose down -v` |

## ۸. رفعِ اشکال

**«docker: command not found» یا شبیهش توی PowerShell:**
Docker Desktop نصب نشده یا هنوز کاملاً بالا نیومده. مطمئن شو آیکونِ نهنگ
(🐳) پایین-راستِ صفحه ثابته، نه در حالِ چرخش.

**پیغامِ «port is already allocated» موقعِ `docker compose up`:**
یه چیزِ دیگه از قبل داره از پورتِ ۵۴۳۲ استفاده می‌کنه (مثلاً یه PostgreSQL که
قبلاً نصب کردی). یا اونو ببند، یا توی `docker-compose.yml` خطِ
`"5432:5432"` رو به `"5433:5432"` تغییر بده (و `DATABASE_URL` توی `.env` رو
دست نزن، چون این فقط پورتِ بیرونیه، ارتباطِ داخلیِ بین کانتینرها رو عوض
نمی‌کنه).

**ربات به `/start` جواب نمی‌ده:**
پنجره‌ی PowerShell که `docker compose up` توش اجرا شده رو نگاه کن (یا
`docker compose logs -f bot` بزن). اگه خطایی درباره‌ی `MAIN_BOT_TOKEN` یا
`TokenValidationError` دیدی، یعنی توکن رو درست توی `.env` نچسبوندی — دوباره
چک کن فاصله یا کاراکترِ اضافه نداشته باشه.

**خطای مربوط به `ENCRYPTION_KEY`:**
اگه پیغامی شبیهِ «Fernet key must be 32 url-safe base64-encoded bytes» دیدی،
یعنی موقعِ کپی‌کردنِ کلید یه بخشیش جا افتاده. مرحله‌ی «ساختنِ کلیدِ رمزنگاری»
رو دوباره انجام بده و مطمئن شو کلِ رشته (بدونِ فاصله‌ی اضافه در اول/آخر) کپی
شده.

**می‌خوام کاملاً از اول شروع کنم:**
```powershell
docker compose down -v
docker compose up -d --build
```
این همه‌ی دیتای دیتابیس رو پاک می‌کنه و از صفر می‌سازتش (مایگریشن‌ها دوباره
خودکار اجرا می‌شن).

**هنوز گیر کردم:**
خروجیِ کاملِ `docker compose logs bot` رو کپی کن و بفرست — از روی پیامِ خطا
می‌شه دقیق‌تر مشکل رو پیدا کرد.
