# کسب‌وکار هوشمند (Smart Business)

پلتفرمِ چندمستأجریِ (multi-tenant) SaaS برای **فروشگاه‌هایِ تلگرامی**. هر فروشگاه‌دار با یه ربات تلگرامیِ اختصاصیِ
خودش (با توکنِ خودش) صاحبِ یه فروشگاهِ هوشمند می‌شه که با هوش مصنوعی به مشتری‌ها جواب می‌ده، سفارش تشخیص می‌ده،
سبدِ خرید و کمپین و پیامِ همگانی داره، و صاحبِ فروشگاه همه‌چیز (محصول، کیف‌پول، گزارش، CRM، حسابداری، دستیارِ
مدیریتی) رو از طریقِ یه رباتِ مدیریتیِ مرکزی («ربات اصلی») کنترل می‌کنه.

> وضعیتِ پروژه، چک‌لیستِ کارهایِ باقی‌مونده و محدودیت‌ها: **`docs/PROJECT_COMPLETION.md`**

## قابلیت‌ها

**برایِ فروشگاه‌دار (ربات اصلی)**
- ثبت‌نام با کدِ تایید، گیتِ کانالِ اجباری، اعتبارِ آزمایشی، کدِ معرف.
- اتصالِ رباتِ فروشگاهی (توکنِ رمزنگاری‌شده)، آموزشِ AI، کانالِ دانش، **پیش‌نمایشِ ربات** (رایگان).
- محصولات با موجودی و رزرو، ایمپورتِ اکسل، سفارش‌ها (تایید/رد/پیشرفتِ وضعیت)، حالتِ مشاوره.
- **کیف‌پول**: شارژ (زرین‌پال / کارت‌به‌کارت / بله‌پی)، هزینه‌یِ AI بر اساسِ توکنِ واقعیِ مصرفی، تاریخچه، هشدارِ کم‌بودنِ موجودی.
- **سبدِ خرید** (دکمه‌ای + ویرایش با AI در چت)، پرسش‌هایِ چک‌اوتِ قابلِ تنظیم، پرداختِ آنلاینِ بله‌پی.
- **کمپین** (تخفیفِ درصدی/ثابت با کد، محدودیتِ مصرف)، **پیامِ همگانی** (به همه یا یه بخش)، گزارشِ دوره‌ای و **شبانه**.
- 🧩 **سوال‌هایِ بی‌جواب**: رباتت جوابِ چه سوال‌هایی رو نمی‌دونه (بدونِ هزینه‌یِ AI).
- 📚 **پرسش‌وپاسخ‌هایِ تاییدشده**: تو جواب می‌نویسی، ربات یاد می‌گیره (فقط با تاییدِ خودت).
- 👥 **مشتری‌ها (CRM)**: بخش‌بندیِ خودکار (وفادار/فعال/جدید/در حالِ ریزش/بدونِ خرید)، یادداشت و برچسب، پیام به بخش، خلاصه‌یِ هوشمند.
- 💬 **دستیارِ مدیریتی**: از آمارِ فروشگاهت سوال بپرس (فقط‌خواندنی؛ هیچ تغییری نمی‌ده).
- 🧮 **حسابداری**: فروشِ خالص/تخفیف/کمپین/پرفروش‌ها در بازه‌هایِ امروز/۷ روز/۳۰ روز/ماهِ شمسی + خروجیِ اکسل.

**برایِ ادمینِ پلتفرم (ربات اصلی)**: کاربران، پرداخت‌ها، طرح‌هایِ قیمت، کدِ تخفیف، کانال‌هایِ اجباری، تنظیمِ کلیدهایِ AI
(با استخرِ کلید + fallback + circuit breaker)، قیمت‌گذاریِ کیف‌پول، سوییچ‌هایِ اضطراری، نگهبانِ محتوا، گزارشِ ممیزی،
مدیریتِ ادمین‌ها (سوپرادمین/عملیاتی)، اصلاحِ کیف‌پول، 📤 خروجیِ دفترِ کیف‌پول (اکسل).

**برایِ مشتریِ نهایی (رباتِ فروشگاه)**: چتِ AI، عکس/صدا، سفارش با تاییدِ خودِ مشتری، سبد، کدِ تخفیف، پرداختِ آنلاین.

## معماریِ کلی

```
                    ┌─────────────────────┐
   فروشگاه‌دارها  →  │   ربات اصلی (main)   │  →  ثبت‌نام، پرداخت، محصولات، سفارش، کیف‌پول،
   و ادمین          │   یه توکنِ ثابت      │      CRM، حسابداری، دستیار، پنلِ ادمین
                    └─────────────────────┘
                              │  هر فروشگاه‌دار یه توکنِ ربات مجزا ثبت می‌کنه
                              ↓
   ┌───────────┐    ┌───────────┐    ┌───────────┐
   │ رباتِ شاپِ  │    │ رباتِ شاپِ  │    │ رباتِ شاپِ  │  ← مشتری‌هایِ نهایی این‌جا چت می‌کنن
   │  فروشگاهِ ۱ │    │  فروشگاهِ ۲ │    │  فروشگاهِ ۳ │
   └───────────┘    └───────────┘    └───────────┘
```

سه سطح: **ادمینِ پلتفرم** → **فروشگاه‌دار** → **مشتریِ نهایی** (مشتری فقط با رباتِ اختصاصیِ فروشگاه حرف می‌زنه).

**پشته‌یِ فنی**: Python 3.12 · aiogram 3 (polling یا webhook) · FastAPI + Uvicorn · PostgreSQL 16 + SQLAlchemy 2 (async) +
Alembic · Docker Compose · زرین‌پال / کارت‌به‌کارت / بله‌پی · هر سرویسِ AI سازگار با OpenAI API (چت، تحلیلِ تصویر، رونویسیِ صدا).

## شروعِ سریع با Docker (پیشنهادی)

```bash
cp .env.docker.example .env
docker compose build
docker compose run --rm bot python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
# مقدارِ چاپ‌شده رو توی .env جلوی ENCRYPTION_KEY= بذار؛ MAIN_BOT_TOKEN و ADMIN_TELEGRAM_IDS رو هم پر کن
docker compose up -d
docker compose logs -f bot
```

مایگریشن‌ها موقعِ استارت خودکار اجرا می‌شن. راهنمایِ کاملاً گام‌به‌گامِ **دیپلویِ واقعی روی سرور** (دامنه، HTTPS، پشتیبان‌گیری،
ریکاوری): `docs/beginner-deployment-guide.md`. راهنمایِ مصورِ بالا آوردنِ محلی: `docs/docker-quickstart-guide.md`.

## اجرایِ تست‌ها

تست‌ها یه رباتِ فیک (`FakeSession`) دارن که همه‌یِ تماس‌هایِ API تلگرام رو شبیه‌سازی می‌کنه؛ توکنِ واقعی و اینترنت لازم نیست،
فقط PostgreSQL (که Docker Compose بالا میاره).

```bash
docker compose build
docker compose run --rm bot alembic upgrade head
docker compose run --rm bot python3 tests_manual/run_all_tests.py
```

مجموعاً **۵۹ فایلِ تست و ۳۷۰ تستِ جداگانه** (آخرین اجرایِ Docker-تاییدشده: ۵۲ فایل/۳۰۴ تست، ۲۰۲۶-۱۰-۰۷؛ فازِ ۱ تا P1-S5a Docker-تاییدشده (۵۶/۳۳۱)؛ موج‌هایِ W1 [P1-S3]، W2 [P1-S4: وضعیتِ سفارش/«سفارش‌هایِ من»/فاکتور]، W3 [کارت‌به‌کارت با رسید] و W4 [بله‌پی/زرین‌پالِ هر فروشگاه] منتظرِ اجرایِ Docker؛ بعد از هر تغییر `docker compose build` رو یادت نره). برایِ سنجشِ ظرفیت: `tests_manual/load_simulation.py`. فقط یه فایل:
`docker compose run --rm bot python3 tests_manual/run_one.py test_crm.py` (رویِ دیتابیسِ جدا
`kasbokar_test` اجرا می‌شود تا تنظیماتِ پنلِ تو پاک نشود). جزئیات و چک‌لیستِ تستِ دستیِ تلگرام: `docs/testing-guide.md`.

بررسیِ استاتیکِ سریع (بدونِ Docker): `python3 scripts/check_refs.py` و `python3 scripts/check_attrs.py`.

```
app/

  bots/

    main_bot/               # ربات اصلی: router.py + handlers/ (start, panel, products, admin,
                            #   campaigns, knowledge, accounting, crm, assistant) + keyboards/texts/states
    shop_bot/               # رباتِ فروشگاه: handlers/customer.py (چتِ AI، سفارش، سبد، ...)
  services/                 # منطقِ کسب‌وکار (۴۷ فایل، بدونِ وابستگی به aiogram)
  utils/                    # رمزنگاری، اعتبارسنجی، تاریخِ شمسی، ...
migrations/                 # Alembic (head: d4a9c6e2b8f1)

scripts/                    # check_refs.py، check_attrs.py
docs/                       # راهنماها و changelogها
```

## نکاتِ مهمِ معماری

- **هر فروشگاه یه توکنِ ربات مجزا داره.** فروشگاه‌دار توکنِ BotFather رو توی پنل وارد می‌کنه؛ سیستم با یه `getMe` واقعی
  اعتبارسنجیش می‌کنه و رمزنگاری‌شده (Fernet، با `ENCRYPTION_KEY`) ذخیره‌ش می‌کنه. **گمِ `ENCRYPTION_KEY` یعنی همه باید توکن‌شون
  رو دوباره وارد کنن** — جدا و امن نگهش دار.
- **مشتری‌هایِ نهایی هیچ‌وقت مستقیم با ربات اصلی حرف نمی‌زنن.** هر چیزی که باید به فروشگاه‌دار برسه (اعلانِ سفارش، رسید) از
  طریقِ *ربات اصلی* می‌ره. `file_id`هایِ تلگرام بینِ دو Bot قابلِ انتقال نیستن، پس عکس‌ها دانلود و دوباره آپلود می‌شن.
- **پیام‌هایِ پشت‌سرهمِ مشتری debounce می‌شن** (پیش‌فرض ۳ ثانیه) تا چند پیامِ جدا یه‌جا و با یه جواب پردازش بشن.
- **هزینه‌یِ AI از کیف‌پولِ فروشگاه‌دار کم می‌شه** و فقط بعد از موفقیتِ واقعیِ فراخوانی. شکستِ AI هیچ هزینه‌ای ندارد.
- **امنیتِ AI**: متنِ مشتری همیشه «داده» حساب می‌شه، نه دستور؛ هیچ‌جا به AI ابزارِ نوشتن (تغییرِ سفارش/کیف‌پول/محصول) داده
  نمی‌شه. دستیار و خلاصه‌یِ CRM فقط آمارِ تجمیعی می‌بینن، نه نام/تلفن/آدرسِ مشتری.
- **پرداختِ کارت‌به‌کارت یه مبلغِ منحصربه‌فرد می‌گیره** (چند تومان پسوندِ تصادفی) تا واریزیِ واقعی با پرداختِ در انتظار مچ بشه.
- **آپدیت بدونِ از دست رفتنِ دیتا**: مایگریشن‌ها افزایشی‌ان و موقعِ استارت خودکار اجرا می‌شن؛ قبل از هر آپدیتِ بزرگ
  پشتیبان بگیر (`docs/beginner-deployment-guide.md`، بخشِ پشتیبان‌گیری).
